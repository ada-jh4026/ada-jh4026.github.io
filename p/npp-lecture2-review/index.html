NPP Lecture 2 Review: NumPy & Pandas

Topics: NumPy arrays · vectorised operations · broadcasting · Pandas Series/DataFrame · data cleaning · groupby · merging · time series

Part 1: NumPy

1. Import conventions and pitfalls

import numpy as np            # conventional alias
from numpy import *           # ❌ dangerous — overwrites builtins like sum/max

2. Core concept: ndarray

  • NumPy's fundamental object.
  • list vs array: a list stores pointers to objects, an array stores values contiguously — arrays are faster and use less memory.
  • Don't use the built-in array module: only 1-D and inflexible types.

3. Creating arrays

Method Example Notes
np.array np.array([1,2,3]); np.array([[1,2],[3,4]]) from lists; same-depth lengths must match
np.zeros np.zeros(3); np.zeros((3,3)) all zeros
np.ones np.ones((3,3)) all ones
np.full np.full(shape, value) fill a value
np.arange np.arange(start, stop, step) excludes stop
np.linspace np.linspace(0,10,6) fixed count, includes stop
np.eye np.eye(3) identity matrix

4. Array attributes

a = np.eye(3)
a.ndim      # 2      number of dimensions
a.shape     # (3,3)  size of each dimension
a.size      # 9      = np.prod(shape)
a.nbytes    # 72     = 9 × 8 bytes
a.dtype     # float64

5. Shape manipulation

  • .reshape(4,3) / .reshape(3,-1): change shape, size unchanged; -1 is inferred and may appear only once.
  • .ravel() / .flatten(): flatten to 1-D (order="K" follows memory order).
  • .T: transpose.
  • 1-D vectors: np.matmul(a,b) and np.matmul(b,a) may differ (row/column not strictly distinguished).

6. Types (dtype)

  • Inferred: [1,2.5,3] → float; [1,2,"Hi"] → str.
  • Explicit: np.array([...], dtype=np.int32).
  • Pitfall: int_arr[1] = 3.5 silently truncates to an integer (no error).

7. Operations and broadcasting

  • Element-wise operators + - * / ** % (map to np.add/subtract/multiply/divide/power/mod).
  • Matrix multiplication: @ / np.matmul / np.dot.
  • Broadcasting: arrays of different shapes can operate; the smaller is broadcast to the larger (at least one dimension compatible).

8. Indexing and slicing

  • Multi-dim index arr[0,0]; multi-dim slice arr[1:3,1:6:2] (== arr[slice(1,3), slice(1,6,2)]).
  • Slice assignment arr[1:3,1:3]=0 follows broadcasting.
  • ⚠️ View pitfall: new = old[1:3,1:3] is a view — mutating new mutates old; use .copy() to avoid.
  • Boolean indexing: arr[arr>5]; arr[arr%3==0]=-1.

9. Linear algebra (np.linalg)

Method Purpose
np.linalg.det(A) determinant
np.linalg.eig(A) eigenvalues/vectors
np.linalg.norm(A) norm
np.linalg.inv(A) matrix inverse (direct method)
np.linalg.solve(A,b) solve linear system (prefer to inv)

10. Record arrays (prelude to Pandas)

arr = np.rec.array(...)
arr["val_1"]        # access a field by name
arr.val_2[1]

Part 2: Pandas

11. Import and Series

import pandas as pd
  • Series: a 1-D labelled array — like a NumPy array but indexed by labels; behaves like a fast dict.
  • Create: pd.Series(data=list) / pd.Series(data, index=labels, name="...") / pd.Series(arr) / pd.Series(dic) (keys become the index).
  • Select by label ser["first name"].
  • ⚠️ Operations align on the index: ser1 + ser2 aligns by label, not position.

12. DataFrame

  • A 2-D table (like a spreadsheet): rows = records/index, columns = fields.
  • Create: pd.DataFrame(data, index=[...], columns=[...]) or a dict {"col":[values...]}.

13. Reading and writing

Method Example Notes
pd.read_csv pd.read_csv("df1.csv") 30+ parameters
index column pd.read_csv(..., index_col=0) use an existing column as index
to_csv df.to_csv("example", index=False) write back
pd.read_excel/to_excel read_excel("f.xlsx", sheet_name="Sheet1") data only, no formulas/charts

14. Selection

  • .columns / .index: column names / index.
  • Single column df["Y"] (returns a Series); multiple columns df[["Y","Z"]].
  • SQL-style df.Y: discouraged, has limitations.
  • .iloc (position): df.iloc[0,:], df.iloc[:,0], df.iloc[[1,2],0] (.at is similar).
  • .loc (label): df.loc["A"], df.loc["B","Y"], df.loc[["A","B"],["Z","Y"]].
  • Order: loc/iloc put rows before columns (same as NumPy, opposite of Python lists).

15. Add/remove

  • New column df["new"] = df["Z"] + df["Y"] (a column is just a Series).
  • Remove df.drop("new", axis=1) / df.drop("A", axis=0): not in-place by default — pass inplace=True.
  • del df["col"]: in-place delete.

16. Conditional filtering

  • df[df>0], df[df["Z"]>0], df[(df["X"]>0)&(df["Y"]>1)] (df>0 is a boolean DataFrame).
  • Combine with & (and), | (or); each condition must be parenthesised.
  • .isin (membership), .isnull/.notnull (null checks).

17. Index operations

  • reset_index(): back to 0,1,2…; set_index("col"): not in-place by default.
  • MultiIndex: pd.MultiIndex.from_arrays([[...],[...]]); select by level mdf.loc["Player 1", :], mdf.xs("Test 1", level=1) (levels start at 0).

18. Common operations and statistics

  • .head(): peek at the first rows.
  • .unique() / .nunique(): unique values / count of unique values.
  • .value_counts(): occurrence counts.
  • .duplicated() / .drop_duplicates(inplace=True): find/drop duplicate rows.
  • Statistics: .mean() .std() .median() .sum() .max() .min() (watch numeric_only=True).
  • .describe(): summary (can .transpose()).

19. map and apply

  • .map: df["col1"].map(lambda p: p - mean) — element-wise, not in-place.
  • .apply: df["col1"].apply(f, n=4) or args=[4] for extra args; can use builtins like len.

20. Types and missing values

  • .dtype / .dtypes: one column / all columns.
  • .astype("float64"): converts (not a forced cast).
  • Types: float64 / int64 / object (strings are stored as object).
  • NaN: missing values are NaN, always float64.
  • Check: df.isnull() / df.notnull().
  • ⚠️ Effect on math: df.sum() skips NaN by default; df.sum(skipna=False) propagates NaN.
  • dropna(): drop by row/column/threshold (axis=1, thresh=2).
  • fillna(value="FILL") / df["A"].fillna(df["A"].mean()): fill.
  • replace: swap "Unknown" etc. for np.nan.

21. Grouping and pivoting

  • df.groupby("Course"): returns a GroupBy object.
  • .groups / .get_group("NPP"): inspect groups / fetch one group.
  • Aggregations: .mean() .std() .max() .min() .count() .describe().
  • .agg: df.groupby(["Course"]).agg([len,"min","max"]) custom aggregation.
  • pivot_table(values, index, columns, aggfunc, fill_value): reshape + aggregate; aggfunc can be a function/list/dict.

22. Combining

  • pd.concat([df1,df2,df3]): glue; vertical by default (axis=0), horizontal with axis=1.
  • pd.merge(left,right,how="inner",on="key"): SQL-JOIN-like.
    • how: inner (intersection) / outer (union) / left / right.
    • multi-key on=["key1","key2"].
  • .join: left.join(right) merges columns on the index; how="outer".

23. Visualisation

  • .plot.hist(): histogram.
  • .plot.scatter("A","B"): scatter plot.

24. Time series

  • Parse dates: pd.read_csv("Tide.csv", index_col="Date", parse_dates=True, dayfirst=True).
  • .sample(n=5): random sample.
  • Date parts: df.index.day / .month / .date.
  • .resample("D").mean() / df["Hs"].resample("ME").max(): aggregate by date, can fill gaps.
  • .asfreq("ME"): take points at a frequency without aggregating.
  • pd.to_datetime(dates, format="mixed", dayfirst=True, utc=True): build a DatetimeIndex.
  • Date ambiguity: numeric dates must consistently be DD/MM/YYYY or MM/DD/YYYY.

Common pitfalls ⚠️

  1. np.arange excludes the stop; np.linspace includes it.
  2. NumPy slices are views (mutating them changes the original); Pandas drop/set_index/map are not in-place by default.
  3. Pandas multi-condition filters must be parenthesised and use &/| (not and/or).
  4. Series arithmetic aligns on the index label, not position.
  5. df.sum() skips NaN by default; pass skipna=False to propagate.
  6. Assigning a float into an integer array silently truncates.
